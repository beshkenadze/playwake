# Private GStreamer runtime for the SteamOS bundle.
#
# These are SteamOS's own packages (repo extra-3.9), so the plugin ABI and the
# library versions match the system exactly. SteamOS already ships GStreamer
# core/base/good, the Vulkan plugins, PyGObject, evdev, libnice, libva, ffmpeg
# and libXRes. The packages below add only what it lacks: webrtcbin, the VA-API
# plugin, the libav decoder and libsrtp2.
#
# Refresh on a SteamOS device with packaging/refresh-runtime-packages.sh.
